# Issue labels

Maintainers apply these labels on GitHub. This file is the list of names. It does not create the labels.

| Label | Meaning | When to use |
| --- | --- | --- |
| `good first issue` | A small task with the outcome already described. | A new contributor can finish it from the spec or the docs, without a design discussion. |
| `help wanted` | The maintainers want someone to take this. | The task is ready and nobody is doing it. |
| `runtime-adapter` | Work on an `AgentRuntime` adapter. | Cursor SDK, OpenCode, or another runtime. |
| `node-tool` | Work on a tool in the AI Server Node toolkit. | A new tool, or a change to one. |
| `runbook` | An allowed action on a server. | Restart, rollback, disk cleanup, or a new action with a command template, precondition, post-check, and timeout. |
| `docs` | Documentation only. | README, the spec, the roadmap, contributing, or a translation. |
| `security` | Hardening that is safe to discuss in public. | A missing control or a threat already described in the spec. An undisclosed vulnerability goes through SECURITY.md, not this label. |
